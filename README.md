# StockFlow

A modern, mobile-friendly inventory management web app for small and medium businesses in Kenya and beyond.

## Features
- Dashboard with sales chart, stock value and low stock alerts
- Products: add, edit, delete and search
- Inventory tracking with recorded stock adjustments
- Sales and purchases that update stock automatically
- Suppliers and customers
- Reports: sales, profit and inventory valuation
- Business settings and currency (KSh by default)
- Secure login with roles (owner, manager, cashier)

## Built with
- HTML, CSS and JavaScript
- Chart.js for charts
- Supabase (PostgreSQL, authentication and Row Level Security)

## Security
- Each business can only see its own data
- Stock changes go through secure database functions
- No business data is stored in the browser
